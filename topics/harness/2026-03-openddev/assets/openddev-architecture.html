OPENDEV Architecture

Compound AI System for CLI Coding Agents — Four-layer architecture with defense-in-depth safety

Scaffolding vs Harness

  • • Scaffolding: pre-runtime assembly (prompt, tools, subagents)
  • • Eager construction guarantees agent readiness at init
  • • Harness: runtime orchestration (dispatch, context, safety)
  • • Clean separation allows independent evolution

Context Engineering

  • • ACC reduces peak context consumption by ~54%
  • • 5 graduated stages vs binary emergency compaction
  • • Dual-memory: episodic summary + working memory
  • • System reminders: inject guidance at decision points

Safety & Extensibility

  • • 5-layer defense-in-depth (prompt → hook)
  • • Schema-level gating > runtime permission checks
  • • MCP lazy discovery: 40% → <5% baseline context
