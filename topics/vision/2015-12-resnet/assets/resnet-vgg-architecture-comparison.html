ResNet vs VGG Architecture

Depth · Block Design · Computational Cost Comparison

Degradation Problem

  • • Deeper plain nets show higher training error
  • • NOT caused by overfitting or vanishing gradients
  • • ResNet reformulates learning as residual mapping
  • • Identity shortcut = parameter-free skip connection

Bottleneck Design

  • • 1x1 conv reduces dimensions before 3x3 conv
  • • Second 1x1 conv restores dimensions
  • • ResNet-152: 11.3B FLOPs (less than VGG-19)
  • • VGG-19: 19.6B FLOPs, 144M params

Key Results

  • • ResNet-152: 19.38% top-1 error (single model)
  • • Ensemble: 3.57% top-5 error on ImageNet test
  • • 5x champion: Classification, Detection, Localization
  • • COCO: 28% relative improvement over VGG baseline
